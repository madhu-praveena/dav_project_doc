# Abstract

Customer churn is a major challenge for subscription-based and service-oriented businesses because losing existing customers can reduce recurring revenue and increase customer-acquisition costs. This project, **ChurnIQ – Customer Churn Prediction and Analytics Dashboard**, presents an interactive web-based interface designed to help users explore customer information, understand churn-risk indicators, and review customer analytics through a centralized dashboard.

The application provides a dashboard with key summary indicators, customer records with risk categories, a customer prediction workspace, analytics visualizations, a model-comparison view, and a conversational AI Copilot demonstration. The interface is developed using HTML, CSS, and JavaScript and is designed to run locally in a modern web browser without requiring a server installation.

The intended machine-learning workflow for a production version includes data collection, data cleaning, exploratory data analysis, categorical encoding, feature scaling where appropriate, model training, and evaluation. Candidate algorithms include Logistic Regression, Decision Tree, Random Forest, Support Vector Machine, K-Nearest Neighbours, and XGBoost. Models can be compared using accuracy, precision, recall, F1-score, and ROC-AUC. The current submitted interface is a front-end prototype: its prediction score is generated by a transparent demo rule and its Copilot uses local demonstration responses. Therefore, displayed values should be treated as illustrative rather than results from a trained model.

ChurnIQ demonstrates how customer data and visual analytics can be organized into a usable decision-support interface. Future development will connect the interface to a verified dataset, a trained and validated machine-learning model, and a backend API so that predictions and performance metrics are generated from real model outputs.
